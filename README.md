# Task Manager

A simple and responsive Task Manager web application built with HTML5, CSS3, and JavaScript (ES6+).

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by:
  - All
  - Pending
  - Completed
- Add tasks using the Enter key
- Responsive and clean user interface
- Dockerfile added

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
